# JustForBuilding（只为建筑）

## 简述

JustForBuilding简称JFB，JFB的目标是构建一个跨模组加载器的Minectaft模组。该模组定义了一套命令集合，并致力于复现Minecraft PE（Pocket Edition）中适用于方块启动器（BlockLauncher）/ 多玩我的世界盒子 的快速建造功能，希望将快速建造功能的思想带入到Java版以实现更轻松的快递建造。

JFB致力于提供如下的基础功能

- line 直线填充，可指定线的长度，同时为其指定生成间隔。
- rect 矩形填充，可指定长度和宽度，用于生成矩形平面，可指定生成的矩形是否使用空心。
- cube 立方体填充，在rect的基础上额外增进了y轴的生成支持，同时允许指定生成的cube是否仅包含框架或是否空心。
- circle radius/diameter 圆形填充，可指定是否使用半径或直径生成圆形平面。可指定是否空心。
- sphere radius/diameter 球体填充，在球面基础上实现三维生成。
- invert 切换建造状态，转为使用空气进行填充
